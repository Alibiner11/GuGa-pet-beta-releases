# GuGu Pet Host macOS 内测版 v0.1.0-beta.8

面向受邀的 macOS Apple Silicon（M 系列芯片、arm64）测试用户，对应项目提交 `6a2f5e5`。

## 下载与校验

- [下载 macOS 安装包（DMG）](https://github.com/Alibiner11/GuGu-pet-beta-releases/releases/download/v0.1.0-beta.8-macos-arm64/GuGu.Pet.Host-0.1.0-beta.8-arm64.dmg)
- [下载 SHA-256 校验文件](https://github.com/Alibiner11/GuGu-pet-beta-releases/releases/download/v0.1.0-beta.8-macos-arm64/GuGu.Pet.Host-0.1.0-beta.8-arm64.dmg.sha256)

安装包 SHA-256：`fe545d97be7955cde237ce32dc4a1774b39086f9968a4cb4cc4a74c3422c6fe6`

打开 DMG 后，将 `GuGu Pet Host.app` 拖入“应用程序”。本包仅适用于 M 系列芯片 Mac，不适用于 Intel Mac、Windows 或 Linux。

## 本次范围

- 本次仅更新 macOS 主程序；Windows 主程序仍保持 beta.7。
- GPT-SoVITS 音色克隆引擎、运行时、模型与平台接口均未变更，继续使用现有的 macOS `v0.1.0` 与 Windows `v0.1.0-windows` 独立能力包。
- PPT 工作台继续处于内测锁定状态；点击入口只会显示“PPT 工作台还在完善中，敬请等待后续更新”。

安装包不包含开发者 API Key、测试账号或用户数据。当前构建未进行 Apple 开发者签名或公证；请确认下载来源后再安装。
