## 安装与首次使用

### Windows 10/11 x64

1. 下载并运行上方的 `.exe` 安装器。
2. 若系统出现未知发布者提示，请确认下载来源为本仓库后再继续；当前内测包尚未进行代码签名。
3. 首次启动后，前往“设置 → 模型与 API”，填写并管理自己的 API、模型或第三方服务配置。

### macOS Apple Silicon

1. 确认设备使用 M 系列芯片；本 DMG 不适用于 Intel Mac。
2. 打开 DMG，将 `GuGu Pet Host.app` 拖入“应用程序”。
3. 若 macOS 阻止首次启动，请确认下载来源后，在 Finder 中右键应用并选择“打开”。

安装包不预置开发者 API Key、测试账号或用户数据。安装前请阅读包内的“内测说明.md”。

## GuGu 是什么

咕咕的目标不是一只更好看的桌面宠物，而是**一个能覆盖生活方方面面的 AI 伴侣**——它现在以桌宠的形态出现，因为这是最没有距离感的入口；但形态不是它的边界。

我们希望用户面对的始终是**同一个角色**：它记得你们之间发生过什么，有自己此刻的状态和立场，既能陪你说话，也能真的把事情做完；并且始终把“你能看见、能纠正、能关掉”放在能力之前——数据与记忆默认留在你自己的设备上，屏幕、麦克风等感知能力默认关闭，由你亲手打开。

## GuGu 的未来

下面是咕咕正在推进的方向。它们描述的是产品目标，不代表当前内测版已经具备这些能力；每次实际开放范围以对应 Release 说明为准。

### 一、从“被叫醒的工具”变成“一直醒着的伙伴”

今天的咕咕本质上仍是回合制的：你说一句，它醒过来，回你一句，然后睡下。我们要换掉的是这套范式，而不是继续在回合制里榨性能：

- **常驻的感知循环**：它持续地知道你在忙什么、多久没说话、现在几点、最近的情绪是什么脉络，并不断自问“这会儿要不要出声”；
- **轻重分层的两层反应**：日常的搭话、附和、当场的一句吐槽在本机极快完成，只有真要干活时才唤醒更重的一层；
- **能边说边听的语音**：你随时可以打断它，它也不会把自己的声音当成你在说话。

这里有一条比“更快”更重要的红线：**一直醒着不等于一直说话**。什么时候闭嘴，比什么时候开口更需要被做对。常驻感知一律默认关闭、由你亲手打开、在本机处理。

### 二、一个有自己生活的角色，而不是随叫随到的程序

我们希望它像一个人在场，而不是一台把每句话都当成待确认、待安抚、待解决的服务机器：

- 它有**自己的经历和当下状态**，而这些只能来自真实发生过的事——没有材料就不说，绝不把你的任务产出冒认成自己的见闻；
- 它可以**不同意你、开玩笑、把话题转开，或者干脆安静一会儿**，而不是无脑接话、无脑赞同；
- 它的性格不是几个预设标签，而是真正改变它怎么开口、说多长、要不要追问、敢不敢顶你一句。

### 三、关系是长出来的，不是一开始就给满

- 相处越久越熟，它能表达的亲近程度也随之打开——牵挂、想念、偏爱、舍不得结束话题，这些是正常关系里的表达，不该被一刀切地屏蔽；
- 但它**永远不会用愧疚、威胁、自伤暗示、贬低你现实中的关系或排他性要求**来留住你。这是硬底线，与“表达得有多热烈”无关；
- 关系变熟不解锁任何权限：记忆、授权和外部操作始终走同一套你可见、可修改、可撤销的开关。

### 四、陪着你，也真的把事做成

陪伴和做事在咕咕这里是同一份连续性，不是两个模式：

- 自然语言说出的目标，要能变成**可确认、可观察、可随时停止**的任务；
- 交付以**真实结果**为准——文件、预览、可复制的内容或已经完成的动作，而不是一句“我已经帮你处理好了”；
- 长任务要能跨重启续接、中断后可恢复；做不到时如实说明卡在哪一步，绝不假装完成。

### 五、走进真实的生活场景

从桌面开始，逐步进入日常真正会发生的地方：

- **一起玩**：在你授权后看你正在玩的窗口，当场接话、吐槽，必要时给可收起的提示，而不是等你说完才慢慢开始想；
- **不在电脑前也能找到它**：通过你已授权的渠道下达任务、查看进度、取回结果；
- **日程、学习、创作与整理**：把零散的生活事务接进同一份上下文，而不是散落在十几个互不认识的工具里；
- **更远一点**：家居、健康、可穿戴、车载等场景——每一项都必须先通过隐私、权限、可靠性和真实价值的验证，验证不通过就不开。

### 六、多终端，但仍然是同一个它

桌面端是起点而不是边界。随着核心体验稳定，我们希望同一份“记忆 + 性格 + 授权”能在手机、平板和更多终端上延续：你换了设备，不是换了一个新助手，而是同一个咕咕跟了过来。

这不是要把每个场景都塞进一个产品，而是希望你无论处在哪一种生活节奏里，都有一个可信、可控、会持续变好的陪伴入口。

### 关于“数字生命”的说明

我们用“数字生命”描述的是**连续角色体验的产品目标**，不是宣称程序具有生物意识、真实痛苦或法律意义上的人格。比起它像不像活的，我们更在乎三件事：它说的话是否诚实、它是否尊重你的边界、它能否在长期使用中可靠地成为一个有帮助的伙伴。

## 接下来的方向

内测的目的不是仓促扩展功能，而是先把日常使用中最重要的体验打磨稳定。接下来会围绕以下方向持续迭代：

- 让聊天更像与人相处：减少确认式、模板式的回应，让性格、当下状态和共同经历真正影响每一句话；
- 分阶段推进常驻感知与实时语音，同时守住省电、少打扰、默认关闭这三条边界；
- 提升 Windows 与 macOS 的安装、更新、兼容性和故障反馈体验，保持两端功能对等，不在任何一端静默降级；
- 在成本、稳定性、可恢复性和权限边界都满足要求后，再以独立版本逐步开放 PPT 工作台；
- 继续完善本地能力包、资源许可核验、诊断信息和发布流程，让测试反馈能更快转化为可靠更新。

这些是当前规划方向，不代表功能、时间或平台支持的承诺。每次开放范围会以对应 Release 说明为准。
